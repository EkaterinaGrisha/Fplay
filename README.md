# ПРОФСИЛА — игра-профориентация

Веб-игра для школьников 14–18 лет на мероприятиях СЭИ (Социально-экономический институт). Игрок получает случайного персонажа, проходит жизненные ситуации и узнаёт свою «профессию-суперсилу» среди пяти направлений подготовки СЭИ.

Одна игра в двух режимах, всё в одной папке:

- **Личный режим** — на телефонах по QR-коду, у каждого свой итог. Публикуется через GitHub Pages из этого репозитория;
- **Общий режим** — на проекторе, весь класс голосует руками, работает полностью офлайн.

Три длительности: блиц (5–7 минут), стандарт (15 минут) и глубокий режим (30–40 минут). На телефоне заданий в каждой длительности больше, чем на проекторе: один человек отвечает быстрее, чем класс голосует руками. Задания каждый раз выпадают случайно из банка, по фиксированному числу из каждого тематического блока.

- План работ: [docs/PLAN.md](docs/PLAN.md)
- Банк заданий для вычитки: [docs/BANK.md](docs/BANK.md)
- Живой макет (холст с кликабельным прототипом): https://claude.ai/artifact/UXy1keQkRYGixCHaJHVMCA

## Как запустить

Откройте `game/index.html` двойным щелчком — игра запустится в браузере прямо с диска, интернет не нужен.

В интернете игра живёт по адресу **https://profsila.github.io/** — туда ведёт QR-код. Сайт обновляется сам после каждого изменения папки `game/` в ветке по умолчанию (workflow `.github/workflows/pages.yml`; перед публикацией он запускает проверку банка). Адрес для QR задаётся в `game/config.js`.

- **Личный режим** открывается сразу.
- **QR для телефонов** — кнопка на экране ведущего и на итоге класса: большой QR со ссылкой на игру. **Листовка A4** с тем же QR — `game/flyer.html` (печать из браузера) или готовый `docs/flyer-a4.pdf`.

## Пакет для ведущих

Архив **https://profsila.github.io/profsila.zip** (ссылка «Скачать игру для работы без интернета» есть и на экране ведущего). Внутри одна папка `ПРОФСИЛА`:

- `index.html` — игра, запускается двойным щелчком без интернета;
- `КАК ЗАПУСТИТЬ.txt` — инструкция на одну страницу, открывается в Блокноте;
- `Памятка ведущего.pdf` — подготовка, управление, сценарии уроков на 15 и 40 минут, что делать, если что-то пошло не так (то же самое — страница `game/host.html`);
- `Листовка A4.pdf` — листовка с QR для печати.

Архив собирается сам при публикации. Собрать его вручную: `python3 tools/package.py` → `dist/profsila.zip` (нужен Google Chrome — им печатаются PDF).
- **Общий режим** — кнопка «Для проектора» на старте (или адрес `index.html#projector`). Ведущий выбирает длительность, способ подсчёта голосов («быстро» — отмечает вариант большинства, «точно» — вводит число рук за каждый вариант) и время на голосование: 45 секунд, 1, 1,5 или 2 минуты или без таймера (по умолчанию 45 секунд для «быстро» и 1,5 минуты для «точно»). Управление с клавиатуры или пульта-кликера: `1`–`4` — вариант, `→` / `PageDown` — дальше, `←` / `PageUp` — назад, `Backspace` — отменить выбор, `T` — таймер заново, `+` — ещё 30 секунд, `F` — во весь экран. Игру можно закончить досрочно и сразу подвести итог класса.

## Как править банк заданий

Тексты лежат в `game/content/*.js` — это обычные текстовые файлы, их можно править в любом редакторе. Меняется только текст в кавычках; идентификаторы (`id`, `dir`) трогать не нужно. После правок:

```bash
node tools/bank.js check
```

Скрипт проверяет структуру, длину текстов, контраст цветов и разыгрывает по 20 000 случайных партий в каждом режиме: каждое направление должно встречаться не реже заданного минимума, а у игрока, который отвечает наугад, все направления должны выпадать главной силой примерно поровну. Партии разыгрываются отдельно для проектора и для телефона. Ещё скрипт сверяет метку `?v=` у скриптов в `game/index.html` с версией банка: после правок поменяйте `bankVersion` в `directions.js` и метку в страницах, чтобы браузеры игроков не смешали старые файлы с новыми.

```bash
node tools/bank.js md
```

Эта команда пересобирает [docs/BANK.md](docs/BANK.md) — документ со всеми текстами для вычитки.

## Чем игра отличается от макета

Макет рисовался под пять направлений и данные кафедры. В `game/`:

- вместо логотипа кафедры стоит `game/assets/logo-sei.svg` и подпись «Социально-экономический институт»;
- нет блоков «Учись этому у нас», зарплатных вилок и контактов;
- каталог и профиль на итоге — на пять направлений СЭИ с кодом, профилем и предметами ЕГЭ, на итоге есть словарик, «Знаешь ли ты» и «Попробуй уже сегодня»;
- кроме ситуаций есть экраны «Это или то», «Проверь себя» и командный кейс;
- вместо сцен-иллюстраций цветные баннеры блоков: иллюстрации пробовали, но оставили баннеры.

## Офлайн и данные

Внешних ресурсов нет: шрифты лежат в `game/fonts/`, аватары, иконки и баннеры — векторные. Регистрации, полей ввода и сбора данных в игре нет. Браузер игрока хранит только список уже сыгранных заданий (чтобы в следующий раз выпали другие) и незаконченную партию — до закрытия вкладки.

# ПРОФСИЛА — игра-профориентация

Веб-игра для школьников 14–18 лет на мероприятиях СЭИ (Социально-экономический институт). Игрок получает случайного персонажа, проходит жизненные ситуации и узнаёт свою «профессию-суперсилу» среди семи направлений.

Одна игра в двух режимах, всё в одной папке:

- **Личный режим** — на телефонах по QR-коду, у каждого свой итог. Публикуется через GitHub Pages из этого репозитория;
- **Общий режим** — на проекторе, весь класс голосует руками, работает полностью офлайн.

Три длительности: блиц (5–7 минут), стандарт (15 минут) и глубокий режим (30–40 минут). Задания каждый раз выпадают случайно из банка, по фиксированному числу из каждого тематического блока.

- План работ: [docs/PLAN.md](docs/PLAN.md)
- Банк заданий для вычитки: [docs/BANK.md](docs/BANK.md)
- Живой макет (холст с кликабельным прототипом): https://claude.ai/artifact/UXy1keQkRYGixCHaJHVMCA

## Как запустить

Откройте `game/index.html` двойным щелчком — игра запустится в браузере прямо с диска, интернет не нужен.

- **Личный режим** открывается сразу.
- **Общий режим** — кнопка «Для проектора» на старте (или адрес `index.html#projector`). Ведущий выбирает длительность и способ подсчёта голосов: «быстро» — отмечает вариант большинства, «точно» — вводит число рук за каждый вариант. Управление с клавиатуры или пульта-кликера: `1`–`4` — вариант, `→` / `PageDown` — дальше, `←` / `PageUp` — назад, `Backspace` — отменить выбор, `T` — таймер заново, `F` — во весь экран. Игру можно закончить досрочно и сразу подвести итог класса.

Файлы `.dc.html` — исходники артбордов холста. Они подключают рантайм холста (`support.js`) и открываются в редакторе по ссылке выше, а не как отдельные страницы. Вёрстку, цвета и тексты из них можно переносить в продакшен-код как есть.

## Как править банк заданий

Тексты лежат в `game/content/*.js` — это обычные текстовые файлы, их можно править в любом редакторе. Меняется только текст в кавычках; идентификаторы (`id`, `dir`) трогать не нужно. После правок:

```bash
node tools/bank.js check
```

Скрипт проверяет структуру, длину текстов, контраст цветов и разыгрывает по 20 000 случайных партий в каждом режиме: каждое направление должно встречаться не реже заданного минимума, а у игрока, который отвечает наугад, все семь направлений должны выпадать главной силой примерно поровну.

```bash
node tools/bank.js md
```

Эта команда пересобирает [docs/BANK.md](docs/BANK.md) — документ со всеми текстами для вычитки.

## Направления

Цвет и иконка закреплены за направлением и повторяются в реакции, диаграмме и каталоге. Текст на цветных плашках всегда тёмный `#141033`.

|---|---|---|---|---|
| Экономист | `#FF9F40` | график роста | экономическое мышление | 8,9 : 1 |
| Финансовый аналитик | `#3DDC97` | монета ₽ | финансовое чутьё | 10,3 : 1 |
| Маркетолог | `#FF5FA2` | рупор | креативность | 6,4 : 1 |
| Экономическая безопасность | `#4C7DFF` | щит | чутьё на риски | 4,9 : 1 |
| Бизнес-информатика | `#C99BFF` | `</>` | работа с данными | 8,3 : 1 |
| Сервис | `#2EC4D6` | звонок ресепшена | забота о клиенте | 8,7 : 1 |
| Инноватика | `#FFD23F` | лампочка | изобретательность | 12,6 : 1 |

Тема одна, светлая, для телефона и проектора: фон `#F4F1FF`, карточки `#FFFFFF` с обводкой `#E4DFFA`, плашки `#ECE8FF`, текст `#141033`, вторичный текст `#4E4878` (7,5 : 1), ссылки и фокус `#5B2FD6` (6,7 : 1). Главная кнопка — лаймовая `#D7FF45` с тёмной обводкой и тенью `#141033`. Шрифты: Unbounded (заголовки) и Onest (текст), оба с кириллицей.

## Чем игра отличается от макета

Макет рисовался под пять направлений и данные кафедры. В `game/`:

- вместо логотипа кафедры стоит `game/assets/logo-sei.svg` и подпись «Социально-экономический институт»;
- нет блоков «Учись этому у нас», зарплатных вилок, названий программ и контактов;
- каталог и профиль на итоге — на семь направлений, на итоге есть предметы ЕГЭ, словарик, «Знаешь ли ты» и «Попробуй уже сегодня»;
- кроме ситуаций есть экраны «Это или то», «Проверь себя» и командный кейс;
- вместо сцен-иллюстраций пока цветные баннеры блоков, иллюстрации — этап 4.

## Офлайн и данные

Внешних ресурсов нет: шрифты лежат в `game/fonts/`, аватары, иконки и баннеры — векторные. Регистрации, полей ввода и сбора данных в игре нет. Браузер игрока хранит только список уже сыгранных заданий (чтобы в следующий раз выпали другие) и незаконченную партию — до закрытия вкладки.
